# Lolzinho

Protótipo Angular de catálogo de campeões de League of Legends. Os dados locais em `src/assets/herois.json` vêm do Data Dragon e registram a versão 12.6.1.

## Executar

```sh
npm ci
npm start
```

Abra `http://localhost:4200`. Use `npm run build` e `npm test` para build e testes.

## Dados e ativos

O catálogo local está desatualizado. Registre a versão da fonte e atualize os dados/ativos como uma unidade. League of Legends e seus ativos pertencem aos respectivos titulares; confira os termos aplicáveis antes de publicar.
